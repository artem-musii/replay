# REPLAY judging matrix

Last reconciled with the implementation: **2026-08-28**. The [WebMCP Challenge](https://webmcp.devpost.com/) and [official rules](https://webmcp.devpost.com/rules) define four equally weighted criteria, with WebMCP Leverage first in tie-breaking. This matrix links claims to repository evidence and keeps local implementation, historical public proof, and pending release proof distinct.

Status vocabulary:

- **Implemented locally:** present in current source/tests; final candidate gate or public verification may still be pending.
- **Historical public proof:** verified for commit `f980d28`; retained as evidence but not attributed to the current candidate.
- **Specified; run pending:** an eval/check artifact exists without a recorded result.
