# REPLAY judging matrix

Last reconciled with current local source/tests and separately scoped deployed evidence: **2026-08-28**. The [official challenge page](https://openai.com/webmcp-challenge/) and [rules](https://webmcp.devpost.com/rules) define four equally weighted criteria, with WebMCP Leverage first in tie-breaking, and a **September 3, 2026 at 1:00 PM PDT** deadline. The final submission must provide a functioning live WebMCP URL, public source/instructions/license, English description, free judge access, and a public YouTube demo under three minutes with audio and actual WebMCP use. This matrix links claims to source, tests, public artifact/browser evidence, and remaining external proof without conflating those categories.

Status vocabulary:

- **Implemented in current source:** present in current source/tests, without implying deployment, a native client, or a manual live journey.
- **Deployed and verified:** present in commit `00688d8a51fb783dbf147e08ece60470b8877544`, passed CI, and verified at the public URL within the stated evidence boundary.
- **Historical public proof:** verified for commit `f980d28`; retained as evidence but not attributed to the current release.
- **Specified; run pending:** an eval/check artifact exists without a recorded result.
