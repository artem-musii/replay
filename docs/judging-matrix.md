# REPLAY judging matrix

Last reconciled with the implementation: **2026-08-27**. The [WebMCP Challenge](https://webmcp.devpost.com/) and [official rules](https://webmcp.devpost.com/rules) define four equally weighted criteria, with WebMCP Leverage first in tie-breaking. This matrix links every submission claim to inspectable repository evidence and marks remaining external verification honestly. API claims follow the current [WebMCP draft](https://webmachinelearning.github.io/webmcp/), [Chrome documentation](https://developer.chrome.com/docs/ai/webmcp), and [OpenAI Site Tools documentation](https://learn.chatgpt.com/docs/webmcp) recorded in the repository source of truth.

Status vocabulary:

- **Implemented:** present in source and available in the local product.
- **Implemented; live smoke verified:** source, deterministic coverage, and a direct public in-app browser/tool run exist; this does not imply a supported-model eval pass.
- **Specified; run pending:** the evaluation artifact exists, but no result is claimed.
